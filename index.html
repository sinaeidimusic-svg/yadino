همه داده‌ها فقط در همین مرورگر ذخیره می‌شوند؛ با پاک‌کردن اطلاعات، برنامه به حالت اولیه برمی‌گردد.

هوش مصنوعی گفتگو (1xAi) — جواب‌های واقعی
غیرفعال

با واردکردن کلید 1xAi، یادی جواب‌ها را با مدل زبانی واقعی می‌سازد — کامل و آموزنده، نه خلاصه جست‌وجو. کلید در همان‌جایی که وارد کنی می‌ماند (کد یا تنظیمات) و هرگز آپلود نمی‌شود.

جست‌وجوی وب (TinyFish) — فقط هنگام نیاز
غیرفعال

یادی با این سرویس جست‌وجوی واقعی وب انجام می‌دهد و نتایج تازه را به هوش مصنوعی می‌دهد تا جواب را با آن‌ها بسازد. جست‌وجو فقط وقتی انجام می‌شود که سؤال به اطلاعات به‌روز نیاز داشته باشد (مثلاً خبر، قیمت، امروز) — نه برای سلام!

🔐 کلیدها فقط روی همین دستگاه می‌مانند (یا در دو خط اول کد). این فایل را به کسی نده؛ اگر دادی، اول کلیدها را از کد پاک کن.
💡 راه سریع‌تر: کلیدها را مستقیم در دو خط اول بخش YADINO_KEYS داخل خودِ فایل بگذار تا بدون هیچ تنظیمی کار کند.
نسخه‌ساز (Export) — خروجی تک‌فایل HTML
از همین برنامه با داده‌های خودت یک فایل HTML مستقل بساز

«نسخه مصرف‌کننده» یک تک‌فایل HTML مستقل است:
✅ کتاب‌ها، PDFها (با متن و جلد) و ویدیوها داخلش می‌مانند.
✅ اگر کلیدی وارد کرده باشی، همان کلیدها داخلش می‌ماند؛ اگر نه، چیزی از کلید داخلش نیست.
🔄 بقیه اطلاعات از صفر تنظیم می‌شود — گیرنده نسخه دوباره نام و پایه را انتخاب می‌کند.
🚫 بخش افزودن کلید API و 🚫 گزینه افزودن PDF در آن وجود ندارد.

️
محدودیت‌های نسخه تک‌فایلی
  • ذخیره‌سازی محلی فقط برای همین مرورگر است؛ حساب کاربری مشترک وجود ندارد.
  • همگام‌سازی میان چند دستگاه به Backend نیاز دارد.
  • اتصال به هوش مصنوعی واقعی نیازمند سرویس Backend امن است؛ کلید API داخل این فایل قرار نمی‌گیرد.
  • PDFهای اسکن‌شده متن قابل استخراج ندارند و به OCR نیاز دارند؛ یادینو آن‌ها را صادقانه «نیازمند OCR» علامت می‌زند.
  • فایل‌های PDF بزرگ ممکن است مرورگر را کند کنند؛ از فایل‌های سبک‌تر استفاده کن.
  • اجرای مستقیم فایل HTML ممکن است برخی محدودیت‌ها برای کتابخانه‌های آنلاین داشته باشد؛ در صورت قطع اینترنت، پیام مناسب نمایش داده می‌شود.
